A cross-reference for Cursor, Claude Code, and GitHub Copilot CLI. It includes hooks whose returned output changes execution flow, tool or prompt data, model context, displayed output, session configuration, or workspace behavior. Purely observational hooks whose output is ignored are excluded.

Do not treat exit code 2 as portable. Cursor documents it as a block signal, Claude Code assigns event-specific meanings and exceptions, and Copilot CLI treats it as a warning by default. Copilot makes it a deny only for preToolUse and permissionRequest; for postToolUseFailure it carries recovery context.

Cursor

0 consumes JSON. 2 blocks. Other nonzero exits fail open unless failClosed: true. Invalid output on the six permission hooks blocks even without failClosed.

Claude Code

Valid JSON can be read on every exit code, but an honored exit-2 block wins. HTTP hooks must return 2xx plus decision JSON; HTTP status alone cannot block. Async command hooks cannot control processing.

Copilot CLI

Most failures and timeouts are fail-open. Command preToolUse is fail-closed on non-timeout errors, while its timeout remains fail-open. Exactly one final JSON document must remain on stdout.

Scope, exclusions, and cautions

  • Response, not side effect: an audit hook that edits a file itself is not included unless the host consumes its returned output. Cursor afterFileEdit, for example, can run a formatter but has no response contract.
  • Post-event means no rollback: changing what the model sees after a tool call does not undo file writes, network calls, telemetry, or any other external effect that already occurred.
  • Claude common fields: many events also accept top-level continue, stopReason, systemMessage, and terminalSequence. Event sections can explicitly discard them; this report emphasizes event-specific, documented behavior. Prompt hooks return {ok, reason, impossible?}; agent hooks return {ok, reason} on the supported decision events.
  • Excluded output-ignored events: Cursor afterShellExecution, afterMCPExecution, afterFileEdit, afterTabFileEdit, afterAgentResponse, afterAgentThought, and sessionEnd; Copilot sessionEnd, errorOccurred, and preCompact. Claude events described as side-effect-only are omitted unless they have a specific response that changes host behavior.
  • Cloud and UI differences: each product has event-specific cloud exclusions. Review the “Exit / limits” field before using a hook as a security boundary.
